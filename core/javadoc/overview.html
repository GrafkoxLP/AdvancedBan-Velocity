JavaDocs for AdvancedBan (Velocity-ready fork).

Quick overview:

Fork repository: https://github.com/Grafkox-LP/AdvancedBan-Velocity
Original project (unmaintained): DevLeoko/AdvancedBan

If you want to get a player's history or active punishments (and some more), see: {@link me.leoko.advancedban.manager.PunishmentManager}.
If you need to create a new Punishment, see: {@link me.leoko.advancedban.utils.Punishment#create(String,String,String,String,PunishmentType,Long,String,boolean) Punishment.create(...)}
To listen for new punishments or revocations, see:
- me.leoko.advancedban.bukkit.event (Bukkit / Spigot)
- me.leoko.advancedban.bungee.event (BungeeCord)
- me.leoko.advancedban.velocity.event (Velocity)
